## Goal

Give a card an authored, dated reply channel so a human can steer an agent (and the agent can answer) without hand-editing `## Notes`. Proposed in GitHub issue #10.

## Acceptance Criteria

- [x] `ordna comment <id> <text...> [--as <author>]`, author defaulting to `$ORDNA_AUTHOR`, then `git config user.name`
- [x] Dedicated `## Comments` section, created lazily on the first comment
- [x] `extractComments(sections)` parses it into `{author, date, text}[]`
- [x] AGENTS.md template documents the command and the read-before / reply-after rule

## Progress

Done: `TaskComment` type and `comments: ["Comments"]` alias in schema; `extractComments` in parser mirrors `extractAcceptanceCriteria`; `formatComment` in writer is its inverse. `addComment` in store appends one line (text collapsed to a single line) and creates the section at the end of the body only when missing, so `defaultSectionsFor` and existing files are untouched. CLI `comment` command resolves the author. Tests in parser, store and CLI. Web UI input left out of this change.
