## Goal

Let `.ordna/config.yaml` name the browser tab of `ordna web`. Every board opens as "Ordna", so several boards open at once can't be told apart in the tab bar.

## Acceptance Criteria

- [x] Optional `webTitle` key in config; unset keeps "Ordna"
- [x] Web client applies it to `document.title`
- [x] Documented in the core/web READMEs and the AGENTS.md template

## Notes

## Progress

Done: optional `webTitle` in `configSchema` (no default, so zero-config output is unchanged). It reaches the client through the existing `/api/config` passthrough; `App.tsx` sets `document.title` once config loads. Server tests cover the unset and set cases.
